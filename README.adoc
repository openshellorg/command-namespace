= command-namespace

Hierarchical command namespace: normative spec, JSON Schemas and a D reference registry library.

link:https://github.com/openshellorg/command-namespace/issues[Report Bug] |
link:https://github.com/openshellorg/command-namespace/issues[Request Feature] |
link:https://docs.opensh.org/tools/command-namespace/index.html[Explore the docs]

== About The Project

Part of the OpenShellOrg command-namespace work: the shell finds commands in a hierarchical, task-shaped namespace instead of searching `PATH`.
Design seed: link:https://github.com/openshellorg/project-plans/blob/main/seeds/2026-10-26%20-%20hierarchical-command-namespace.md[project-plans seed]. Concept page: link:https://docs.opensh.org/open-shell-org/concept-command-namespace.html[Command namespace and context requests].

Status: spec + schemas + registry library (v0).
