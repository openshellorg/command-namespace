= Provisional decisions
:description: Open design questions answered provisionally in command-namespace v0, with reasons.
:page-orig-author: Grok Bot on behalf of Ryan Johnson
:page-orig-author-github: AMDphreak

These answers are PROVISIONAL. Any of them can change before v1.

[cols="1,1,3"]
|===
|Question |Provisional answer |Why

|Free-flag sigil
|`+` (for example `+yes`, `++verbose`)
|`-` and `--` already belong to each tool's own flags, and `+` is seldom used by existing CLIs. Repeating it (`+`, `++`, `+++`) maps to `levels`.

|Manifest format
|JSON, validated by JSON Schema (draft 2020-12), with `"manifest": 0`
|It matches the org's existing manifests (shell-framework `manifests/*.json`), every language can parse it without extra libraries, and editors can validate it through `$schema`. SDL (as used by shell-context) is kept as a possible authoring syntax that compiles to this JSON later.

|Fallback name for `install` in legacy shells
|`osh-install`
|`install` already exists on Unix (coreutils `install`), so the front door can't take over that name in shells that still use PATH. `osh-` is a short Open Shell prefix that no common tool uses. Inside the namespace the verb is still `install`.

|Implementation language
|D (LDC), packaged with dub
|The Open Shell runtime and shell-context stubs are in D. It builds native single binaries for Windows, Linux and macOS.

|Legacy subtree name
|`legacy/`
|The name says what the subtree is, and it sorts away from real verbs.
|===
